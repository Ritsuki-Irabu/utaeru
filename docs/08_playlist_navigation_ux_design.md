# Issue #19 プレイリスト導線・責務整理設計

## 1. 目標

プレイリストを一般的な音楽アプリと同じ情報設計に揃え、閲覧と管理の操作を同じ画面で混在させない。

```text
プレイリスト
  └─ プレイリスト一覧
       └─ プレイリスト詳細（曲タイトル一覧）
            └─ 曲詳細（BPMリズム・YouTube MV再生）
```

## 2. 画面ごとの責務

| 画面 | 通常表示 | 管理操作 |
| --- | --- | --- |
| `/playlists` | プレイリストの選択、曲数、公開状態 | 「新規プレイリスト」から作成フォームを開く |
| `/playlists/:id` | プレイリスト名・説明、曲タイトル一覧 | 「プレイリストを管理」を押したときだけ表示 |
| `/songs/:id` | 選択した曲のタイトル・アーティスト・BPM | BPMリズムとYouTube MV再生 |
| `/shared/playlists/:token` | 共有プレイリストの曲タイトル一覧 | 自分のプレイリストへのコピーだけ |

## 3. プレイリスト詳細の通常表示

- 曲はタイトルを主情報、アーティストを補助情報として縦に表示する
- 曲行全体をリンクにし、クリックすると曲詳細へ遷移する
- 通常表示では編集フォーム、曲追加フォーム、共有設定、音声プレイヤーを表示しない
- 曲がない場合は管理画面への導線を表示する

## 4. 管理操作の責務

「プレイリストを管理」パネルに次の操作を集約する。

- 基本情報：名前・説明の変更、プレイリスト削除
- 曲の追加：既存の公開曲から検索して追加
- 曲の管理：曲順・メモの編集、曲の削除
- 共有設定：共有リンクの発行・停止・コピー

管理パネルは初期状態で閉じ、閲覧時の情報量を抑える。操作後は同じ詳細画面に留まり、成功メッセージで結果を通知する。

## 5. 再生ルール

- プレイリスト一覧・プレイリスト詳細・共有プレイリストでは再生しない
- プレイリスト詳細では「連続再生を開始」から曲順にYouTube MVを連続再生できる。再生操作は動画内の標準コントロールで行う
- 曲を選択して `/songs/:id` を開いた後にだけ再生UIを表示する
- 曲詳細からは、遷移元に応じて「プレイリストへ戻る」「共有プレイリストへ戻る」を表示する
- プレイリスト管理者と共有閲覧者で、曲詳細の再生操作は同じにする

## 6. 実装方針

- 既存のPlaylist API・Policy・CRUD APIは維持する
- Vueの責務を `PlaylistsView`（一覧）、`PlaylistDetailView`（閲覧と管理パネル）、`SongDetailView`（再生）に分離する
- 共有画面も曲タイトル一覧へ統一し、曲詳細へ遷移させる
- API仕様を変更しないため、既存データと既存の認可ルールをそのまま利用できる
